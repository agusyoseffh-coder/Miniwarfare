# Mini Warfare (Unity 2022.3, Android FPS)

Mobile team deathmatch (5v5 bots): left thumb = move, right side = look, buttons = FIRE / JUMP / RELOAD.
The scene is generated by `Assets/Editor/BuildScript.cs` during the build.

## Setup GitHub Actions
1. Push all files to a GitHub repo (branch `main`).
2. Run the workflow **1 - Acquire activation file**, download the artifact (.alf).
3. Upload the .alf at https://license.unity3d.com/manual, download the .ulf.
4. Repo > Settings > Secrets and variables > Actions, add:
   - `UNITY_LICENSE` = full contents of the .ulf
   - `UNITY_EMAIL` = Unity account email
   - `UNITY_PASSWORD` = Unity account password
5. Run **2 - Build Android APK** (or push to main). The APK is in the run's Artifacts.

First build takes ~15-30 minutes; later builds are faster thanks to the Library cache.
